# Editor-Ansichten

Über die Eigenschaft `editorViews` der Sandbox-Instanz kannst du mit den Inhalten geöffneter Editoren interagieren: 
Zeilen hervorheben und zu einer bestimmten Zeile springen (dorthin scrollen, den Editor fokussieren und den Cursor 
in die Zeile setzen).

## Zeilen hervorheben

```ts
// highlight a single line in the currently focused tab
sandbox.editorViews.highlightLines(6)

// highlight an inclusive range of lines
sandbox.editorViews.highlightLines([11, 13])
```

Wenn du einen Dateipfad übergibst, wird diese Datei geöffnet (und fokussiert, falls sie es noch nicht ist), bevor die 
Zeilen hervorgehoben werden.

```ts
sandbox.editorViews.highlightLines([5, 7], './public/style.css')
```

## Mehrere Bereiche hervorheben

`highlightLines()` ist additiv: Ein erneuter Aufruf fügt einen weiteren hervorgehobenen Bereich hinzu, anstatt den 
vorherigen zu ersetzen. So können mehrere voneinander getrennte Bereiche gleichzeitig im selben Editor hervorgehoben 
werden.

```ts
sandbox.editorViews.highlightLines(1)
sandbox.editorViews.highlightLines([11, 13])
// both line 1 and lines 11-13 are now highlighted
```

Hervorgehobene Zeilen bleiben auch nach dem Schließen ihres Editor-Tabs erhalten und werden automatisch 
wiederhergestellt, wenn dieselbe Datei erneut geöffnet wird.

## Hervorhebungen entfernen

```ts
// clear highlights in the currently focused tab
sandbox.editorViews.clearHighlightedLines()

// clear highlights in a specific file
sandbox.editorViews.clearHighlightedLines('./public/style.css')

// clear highlights across every open editor
sandbox.editorViews.clearAllHighlightedLines()
```

Beide Methoden verwerfen außerdem alle gespeicherten Hervorhebungen für die betroffenen Pfade, sodass sie beim 
nächsten Öffnen der Datei nicht wiederhergestellt werden. `clearHighlightedLines()` bewirkt nichts, wenn die 
Zieldatei gerade nicht geöffnet ist.

## Zu einer Zeile springen

```ts
// scroll the currently focused tab so line 11 is centered in view, place the cursor there and
// focus the editor
sandbox.editorViews.goToLine(11)

// open (if needed), focus and go to a line in a specific file
sandbox.editorViews.goToLine(11, './server.js')
```

Hervorheben und Springen zu einer Zeile sind unabhängig voneinander — du kannst das eine ohne das andere aufrufen. 
Das gilt auch, wenn eine Datei geöffnet wird, die noch nicht geladen ist: `highlightLines()` und `goToLine()` öffnen 
und fokussieren die Zieldatei jeweils selbst; du musst vorher nicht `editorTabs.open()` aufrufen.
