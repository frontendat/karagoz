# Editor-Tabs

Über die Eigenschaft `editorTabs` der Sandbox-Instanz kannst du mit Editor-Tabs interagieren; sie wird auch intern 
für die Interaktion zwischen Explorer und Editor-Tabs verwendet.

## Dateien öffnen

Der wichtigste Anwendungsfall ist das Öffnen von Dateien zum Bearbeiten, nachdem sichergestellt ist, dass die 
Dateien gemountet sind.

```ts
await container.mount(/* FileSystemTree or snapshot */)
await sandbox.bootstrap()

sandbox.editorTabs.open(
  // File path, will be used as a unique ID as well.
  './public/index.html',
  
  // Optional label to by display for the editor tab.
  // If not provided the file name will be extracted 
  // from the path and used as a label.
  'HOME PAGE',
  
  // Optional context. 
  // Currently only supports suppressClose to hide the close button,
  // prventing the user from closing the tab.
  {
    suppressClose: true,
  }
)
```

Wird eine bereits geöffnete Datei erneut geöffnet, erhält einfach der entsprechende Editor-Tab wieder den Fokus.

Beim Öffnen einer schreibgeschützten Datei (passend zu `sandbox.explorer.readonly`) wird neben der Tab-Beschriftung 
ein Schloss-Icon angezeigt, und der Dateiinhalt kann im Editor nicht geändert werden.

## Dateien schließen

Editor-Tabs lassen sich auch programmatisch schließen, indem du den Dateipfad übergibst.

```ts
sandbox.editorTabs.close('./public/index.html')
```
