# Karagöz Sandbox

::hint{variant='destructive'}
Denk daran, dass Karagöz sich noch in aktiver Entwicklung befindet und sich Dinge in naher Zukunft ändern können.
Die Nutzung in Produktion erfolgt auf eigenes Risiko.
::

::hint
Feedback und Verbesserungsideen sind willkommen – eröffne dazu gerne Issues und Discussions im 
:external-link{href='https://github.com/frontendat/karagoz' content='GitHub-Repo'}. 

Beiträge zum Code werden ebenfalls angenommen und geschätzt, sobald ein geeigneter Prozess definiert ist.
::

Die Idee hinter Karagöz Sandbox ist es, eine einfache UI für die Arbeit mit
:external-link{href='https://webcontainers.io' content='WebContainern'} bereitzustellen.

Falls du WebContainer noch nicht kennst, schau dir
:external-link{href='https://webcontainer-tutorial.pages.dev' content='dieses Tutorial'} an.

Kurz gesagt handelt es sich um eine browserbasierte Laufzeitumgebung, die von StackBlitz entwickelt wurde. Sobald du 
einen WebContainer im Browser bootest, kannst du eine Sammlung von Dateien darin mounten und Prozesse starten – etwa 
Abhängigkeiten installieren oder einen Entwicklungsserver starten – über die Shell oder deinen bevorzugten 
Paketmanager (NPM, PNPM und Yarn sind vorinstalliert).

Mit Karagöz Sandbox obendrauf bekommst du so etwas wie das hier:

::hint
Aufgrund von Einschränkungen im Design der WebContainer API kann **nur eine** WebContainer-Instanz gleichzeitig 
laufen.
Deshalb beendet das Starten einer Demo auf einer der Dokumentationsseiten alle zuvor laufenden Demos.
::

::hint
Je nach Anwendungsfall benötigst du eventuell eine kommerzielle Lizenz, um die WebContainer API zu nutzen.
Weitere Informationen findest du auf :external-link{href='https://webcontainers.io/enterprise' content='dieser Seite'}.
::

::demo-runner
:sandbox-demo-full
::

Karagöz Sandbox steht auf den Schultern von Riesen, um eine einfache, intuitive UI zu bieten.

Neben WebContainern verwendet es :external-link{href='https://codemirror.net' content='CodeMirror'} zum Bearbeiten 
von Code und :external-link{href='https://xtermjs.org' content='Xterm.js'}, um mit dem Terminal zu interagieren und 
die Ausgabe laufender Prozesse anzuzeigen.
