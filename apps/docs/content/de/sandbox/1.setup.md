# Einrichtung

Die Einrichtung von Karagöz Sandbox ist unkompliziert. Folge einfach den Schritten unten.

## Installation

Installiere die folgenden Pakete mit deinem bevorzugten Paketmanager.

```shell
# NPM
npm install --save @karagoz/sandbox @karagoz/shared

# PNPM
pnpm add @karagoz/sandbox @karagoz/shared

# Yarn
yarn add @karagoz/sandbox @karagoz/shared

# Bun
bun add @karagoz/sandbox @karagoz/shared
```

::hint
**`@karagoz/shared`** ist eine separate Bibliothek, die eine Sammlung gemeinsam genutzter (und größtenteils 
unveränderter) :external-link{href='https://www.shadcn-vue.com' content='shadcn-vue'}-Komponenten bereitstellt, die 
in allen Karagöz-Projekten verwendet werden.
::

## Cross-Origin-Isolation

In der Dokumentation der WebContainer API heißt es:

> WebContainer benötigen SharedArrayBuffer, was wiederum voraussetzt, dass die Website, auf der sie laufen, cross-origin-isoliert ist. Deshalb musst du COOP/COEP-Header setzen:
> ```kotlin
> Cross-Origin-Embedder-Policy: require-corp
> Cross-Origin-Opener-Policy: same-origin
> ```

Mehr zu diesem Thema findest du
unter :external-link{href='https://webcontainers.io/guides/configuring-headers' content='Configuring Headers'}
in der Dokumentation der WebContainer API.

Um deinen Entwicklungsserver zu konfigurieren, nimm folgende Anpassungen vor:

### Vue.js-Projekt

Füge Folgendes in deine Vite-Konfiguration ein:

```typescript
export default defineConfig({
  server: {
    headers: {
      'Cross-Origin-Embedder-Policy': 'require-corp',
      'Cross-Origin-Opener-Policy': 'same-origin',
    },
  },
})
```

### Nuxt-Projekt

Füge Folgendes in deine Nuxt-Konfiguration ein:

```typescript
export default defineNuxtConfig({
  routeRules: {
    '/*': {
      headers: {
        'Cross-Origin-Embedder-Policy': 'require-corp',
        'Cross-Origin-Opener-Policy': 'same-origin',
      },
    },
  },
  hooks: {
    // routeRules should be enough to get things running, but without the following Nuxt DevTools won't work.
    'vite:serverCreated': (server) => {
      server.middlewares.use((_req, res, next) => {
        res.setHeader('Cross-Origin-Resource-Policy', 'same-origin')
        res.setHeader('Cross-Origin-Embedder-Policy', 'require-corp')
        res.setHeader('Cross-Origin-Opener-Policy', 'same-origin')
        res.setHeader('Access-Control-Allow-Origin', 'https://localhost:3000')
        next()
      })
    },
  },
})
```

## Styles

Nach der Installation musst du die Styles importieren.

Das kannst du zum Beispiel in deinem Einstiegspunkt so machen:

```typescript
/* main.ts */
import '@karagoz/shared/dist/karagoz-shared.css'
import '@karagoz/sandbox/dist/karagoz-sandbox.css'
```

Oder im Haupt-Stylesheet:

```css
/* main.css */
@import "@karagoz/shared/dist/karagoz-shared.css";
@import "@karagoz/sandbox/dist/karagoz-sandbox.css";
```

## I18N

Karagöz Sandbox verwendet `vue-i18n`, um eine lokalisierte Oberfläche bereitzustellen. Übersetzungen für Arabisch, 
Englisch und Deutsch sind bereits enthalten. Da es nur wenige Texte zu übersetzen gibt, kannst du ganz einfach auch 
deine Sprache unterstützen.

```typescript
/* main.ts */

import { createApp } from 'vue'
import App from './App.vue'
import { createI18n } from 'vue-i18n'
import { i18nMessages } from '@karagoz/sandbox'

const i18n = createI18n({
  locale: 'en',
  messages: { 
    /* Already supported languages */ 
    ar: { ...i18nMessages.ar },
    de: { ...i18nMessages.de },
    en: { ...i18nMessages.en },
    /* Additional language */
    fr: {
      /* All Karagöz translations are under the krgz key/prefix. */
      krgz: {
        /* ... */
      }
    }
  }
})

createApp(App).use(i18n).mount('#app')
```

Wenn du Typsicherheit möchtest und fehlende Übersetzungen vermeiden willst, kannst du `vue-i18n` wie folgt erweitern:

```typescript
/* vue-i18n.d.ts */

import { i18nMessages } from '@karagoz/sandbox'

type MessageSchema = typeof i18nMessages.en

/**
 * Provide type intellisense for translation keys and date/number formats.
 */
declare module 'vue-i18n' {
  // define the locale messages schema
  export interface DefineLocaleMessage extends MessageSchema {}
}
```

Damit ist die Einrichtung abgeschlossen. Jetzt kannst du deine erste Sandbox erstellen :)
