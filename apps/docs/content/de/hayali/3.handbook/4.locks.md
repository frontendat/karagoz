# Sperren

Eine **Sperre** macht eine Datei für die Dauer eines Schritts schreibgeschützt. Sie ist nur eine Einschränkung der
Oberfläche: Lernende können eine gesperrte Datei weiterhin öffnen und lesen, nur nicht bearbeiten.

```typescript
{
  id: 'style',
  title: 'Style',
  body: '…',
  adjustments: styled,
  locks: ['index.html'],   // read-only in this step
}
```

`locks` nimmt Pfadmuster entgegen (zum Beispiel `src/**` oder `public/*.css`). Hat ein Schritt Sperren, nennt ein kurzer
Hinweis über dem Schritt-Text die gesperrten Dateien.

## Sperren und Unveränderlichkeit

|  | Sperre | Unveränderlich |
| --- | --- | --- |
| Geltungsbereich | Ein Schritt | Die ganze Lektion |
| Wirkung | Schreibgeschützt in Explorer und Editor | Nie überwacht oder zurückgesetzt |
| Festgelegt mit | `Step.locks` | `Lesson.immutable` |

Beide sind unabhängig voneinander. Eine gesperrte Datei, die nicht unveränderlich ist, wird beim Weitergehen trotzdem
zurückgesetzt. Eine gesperrte Datei kann von [Editor-Direktiven](/hayali/handbook/editor-directives) weiterhin geöffnet,
geschlossen und hervorgehoben werden.
