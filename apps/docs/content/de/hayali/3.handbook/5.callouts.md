# Callouts

Schritt-Texte sind Markdown. Zusätzlich zu normalem Markdown unterstützen sie **Callouts**: hervorgehobene Kästen für
einen Tipp, eine Warnung oder einen Hinweis. Ein Callout ist ein umzäunter Container mit einer Art und einem optionalen
Titel:

```markdown
:::tip A short title
Some helpful advice. It can contain *regular* markdown.
:::

:::warning
No title is fine, too.
:::
```

Standardmäßig gibt es drei Arten:

| Art | Verwende sie für |
| --- | ---------------- |
| `tip` | Ratschläge, die helfen, aber nicht nötig sind. |
| `warning` | Etwas, das schiefgehen oder Arbeit kosten kann. |
| `note` | Neutrale Zusatzinformationen. |

Eine unbekannte Art wird nicht als Callout gerendert, sondern bleibt normaler Text.

## Eigenes Markdown rendern

`KrgzHayali` rendert die Texte seiner Schritte mit den Standardarten. Die Bausteine dahinter sind exportiert, sodass du
dieselbe Syntax in deinem eigenen markdown-it-basierten Rendering nutzen oder eigene Arten hinzufügen kannst:

* [`createCalloutRegistry()`](/hayali/api-reference/functions/createCalloutRegistry) erstellt eine Registry von
  [`CalloutDefinition`](/hayali/api-reference/interfaces/CalloutDefinition)s; mit `register(kind, { variant })` fügst du
  eine hinzu oder ersetzt eine.
* [`calloutPlugin(registry)`](/hayali/api-reference/functions/calloutPlugin) ist das markdown-it-Plugin, das die Container
  in gestaltete Hinweise verwandelt.
* `StepBody` rendert einen Markdown-String mit der Standard-Registry.

```typescript
import MarkdownIt from 'markdown-it'
import { calloutPlugin, createCalloutRegistry } from '@karagoz/hayali'

const registry = createCalloutRegistry()
registry.register('danger', { variant: 'destructive' })

const html = new MarkdownIt().use(calloutPlugin(registry)).render(':::danger Careful\nSharp edges.\n:::')
```
