# Lektions-Schema

Eine Lektion besteht aus einfachen Daten. Das ist Absicht: Du kannst sie in einer Datei halten, generieren, übersetzen
und ohne Browser validieren.

| Konzept | Typ | Was es ist |
| ------- | --- | ---------- |
| Lektion | [`Lesson`](/hayali/api-reference/interfaces/Lesson) | Das Ganze: Basisdateien plus Kapitel. |
| Kapitel | [`Chapter`](/hayali/api-reference/interfaces/Chapter) | Eine betitelte Gruppe von Schritten. |
| Schritt | [`Step`](/hayali/api-reference/interfaces/Step) | Eine Seite Erklärung und der Sandbox-Zustand, um den es geht. |
| Position | [`Position`](/hayali/api-reference/interfaces/Position) | `{ chapterId, stepId }`: wo die Lernenden gerade sind. |

## IDs

Kapitel und Schritte haben eine `id`, die **du** wählst. Schritt-IDs sind innerhalb ihres Kapitels eindeutig, Kapitel-IDs
innerhalb der Lektion. IDs werden nie aus Titeln abgeleitet. Nutze sie, um eine Position zu speichern und wiederherzustellen
oder um Übersetzungen zuzuordnen.

## Was ein Schritt enthalten kann

* `title` und `body` (Markdown, mit [Callouts](/hayali/handbook/callouts)).
* `adjustments` und `removals`: [welche Dateien der Schritt ändert](/hayali/handbook/adjustments-and-removals).
* `locks`: [welche Dateien im Schritt schreibgeschützt sind](/hayali/handbook/locks).
* `editor` und `preview`: [wohin die Aufmerksamkeit gelenkt wird](/hayali/handbook/editor-directives).

Alles außer `id`, `title` und `body` ist optional. Eine Lektion aus einer früheren Version, ohne `editor` oder `preview`,
funktioniert unverändert weiter.

## Validieren

[`validateLesson()`](/hayali/api-reference/functions/validateLesson) prüft eine Lektion gegen den aufgelösten Dateibaum
jedes Schritts und gibt eine Liste von [`LessonIssue`](/hayali/api-reference/interfaces/LessonIssue)s zurück. Eine leere
Liste bedeutet, dass die Lektion gültig ist. Die Funktion wirft nie, auch nicht bei fehlerhaften Eingaben, du kannst sie
also auf aus JSON geladenen Lektionen ausführen.

```typescript
const issues = validateLesson(lesson)
// e.g. { rule: 'missing-file', chapterId: 'intro', stepId: 'shout', path: 'app.js', message: '…' }
```
