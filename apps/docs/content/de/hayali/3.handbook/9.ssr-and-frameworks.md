# SSR und Frameworks

Karagöz Hayali rendert auf dem Server. Die Lektion soll ohne JavaScript und für Suchmaschinen lesbar sein.

## Was der Server rendert

* Jeden Schritt-Text des aktuellen Kapitels im HTML. Schritte, die nicht aktuell sind, sind in der Oberfläche eingeklappt,
  aber trotzdem vorhanden.
* Das Layout, gewählt per CSS (siehe [Layout](/hayali/handbook/layout)).
* Einen Platzhalter statt der Sandbox. Der WebContainer existiert nur im Browser und startet beim Mounten.
* Den Schritt aus `position`, oder den ersten Schritt des ersten Kapitels, wenn du keinen übergibst. Hayali stellt nie
  eine Position aus `localStorage` wieder her.

## Was du bereitstellst

* **COOP/COEP-Header** auf der Seite, damit der Browser WebContainer ausführen kann. In der Entwicklung gibt Hayali eine
  Warnung aus, wenn die Seite nicht Cross-Origin-isoliert ist.
* **Die Stylesheets** von `@karagoz/shared`, `@karagoz/sandbox` und `@karagoz/hayali` in der serverseitig gerenderten
  Ausgabe.
* **Ein frisches `vue-i18n` pro App (und pro Anfrage auf dem Server)** mit zusammengeführtem `i18nMessages` und der
  Sprache aus einer Prop oder deinem Framework.
* **`provideWebContainer(useSandboxBoot().boot)`** in einer Komponente oberhalb von `KrgzHayali`. Das Starten geschieht
  nur beim Mounten, der Aufruf ist also auch beim Rendern auf dem Server sicher.

## Nuxt

So ist genau diese Website eingerichtet, verifiziert durch die Demo auf der Seite [Erste Schritte](/hayali/getting-started).

```typescript
/* nuxt.config.ts */
export default defineNuxtConfig({
  css: ['~/assets/css/karagoz.css'],            // imports the three @karagoz/* stylesheets
  routeRules: {
    '/*': {
      headers: {
        'Cross-Origin-Embedder-Policy': 'require-corp',
        'Cross-Origin-Opener-Policy': 'same-origin',
      },
    },
  },
  modules: ['@nuxtjs/i18n'],
})
```

```typescript
/* i18n/locales/en.ts: merge the single pack */
export default defineI18nLocale(async () => ({
  ...(await import('@karagoz/hayali')).i18nMessages.en,
  /* your own messages */
}))
```

Verpacke die Lektion in eine Komponente, die den WebContainer bereitstellt, nimm die Sprache aus `useI18n()` und rendere
sie als Lazy-Komponente mit `hydrate-on-visible`. Der Text der Lektion bleibt im HTML des Servers, und der WebContainer
startet erst, wenn die Lektion in den sichtbaren Bereich scrollt:

```vue
<template>
  <LazyMyLessonRunner hydrate-on-visible :locale="locale" />
</template>
```

`<ClientOnly>` ist nicht nötig.

## Astro

::hint{variant='destructive'}
Dieses Rezept ist noch nicht verifiziert. Es ist der unterstützte Weg, der sich aus der Funktionsweise von Hayali ergibt,
aber ungetestet.
::

* Rendere die Lektion aus **einer einzelnen Vue-Insel**, die `KrgzHayali` enthält und den WebContainer bereitstellt.
* Erstelle über das `appEntrypoint` der Vue-Integration **pro Insel eine frische `vue-i18n`-Instanz** und führe
  `i18nMessages` hinein.
* Hydratisiere mit `client:visible`, damit der WebContainer startet, wenn die Insel in den sichtbaren Bereich scrollt.
* Liefere die COOP/COEP-Header von deinem Host oder Adapter aus und binde die drei Stylesheets in die Seite ein.

```typescript
/* src/pages/_app.ts, registered with vue({ appEntrypoint: '/src/pages/_app' }) */
import type { App } from 'vue'
import { createI18n } from 'vue-i18n'
import { i18nMessages } from '@karagoz/hayali'

export default (app: App) => {
  app.use(createI18n({ legacy: false, locale: 'en', fallbackLocale: 'en', messages: i18nMessages }))
}
```
