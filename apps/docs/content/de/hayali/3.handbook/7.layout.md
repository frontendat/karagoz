# Layout

`KrgzHayali` hat zwei Layouts: **nebeneinander** (Lektion links, Sandbox rechts, mit Ziehgriff zum Ändern der Größe) und
ein **einzelnes Panel** mit einem Lektion/Sandbox-Umschalter. Welches du bekommst, hängt von der Breite der
**Komponente** ab, nicht vom Viewport. Eine Lektion in einer schmalen Spalte verhält sich also wie eine Lektion auf einem
Smartphone.

## fullLayoutFrom

Die Prop `fullLayoutFrom` legt die Mindestbreite für das Layout nebeneinander fest. Sie akzeptiert die Container-Größen
`xs`, `sm`, `md`, `lg`, `xl`, `2xl`, `3xl` (Standard), `4xl`, `5xl`, `6xl` oder `7xl` (wie bei Tailwinds Container
Queries: `3xl` entspricht 48rem) oder `none`, um immer das einzelne Panel zu verwenden.

```vue
<KrgzHayali :lesson="lesson" v-model:position="position" full-layout-from="4xl" />
```

Die Wahl trifft allein CSS, sodass das richtige Layout schon beim allerersten Aufbau da ist, auch im serverseitig
gerenderten HTML, ohne auf JavaScript zu warten. JavaScript merkt sich nur, welches Panel der Umschalter zeigt, und steuert
den Ziehgriff.

## multiPanelFrom

`multiPanelFrom` wird an die Sandbox weitergereicht, die zwischen Editor, Explorer und Vorschau nebeneinander und einzeln
wechselt. Siehe das [Sandbox-Handbuch](/sandbox/handbook/working-with-panels).

## Größe

Die Komponente füllt ihr Elternelement aus (`height: 100%`). Gib dem Elternelement also eine Höhe, zum Beispiel
`height: 640px` oder ein wachsendes Flex-Kind.

## Die Sandbox ersetzen

Das Sandbox-Panel rendert standardmäßig `KrgzSandbox`. Für eine eigene Anordnung befüllst du den Slot `sandbox`. Er
erhält `ready` (ob die Dateien gemountet sind) und `multiPanelFrom`:

```vue
<KrgzHayali :lesson="lesson" v-model:position="position">
  <template #sandbox="{ ready, multiPanelFrom }">
    <MyCustomSandbox :booting="!ready" :multi-panel-from="multiPanelFrom" />
  </template>
</KrgzHayali>
```

## Rechts nach links

Das Layout folgt der Dokumentrichtung. Die Zurück- und Weiter-Icons der Werkzeugleiste werden in Sprachen mit
Schreibrichtung von rechts nach links gespiegelt.
