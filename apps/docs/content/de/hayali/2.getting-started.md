# Erste Schritte

In dieser Anleitung baust du eine kleine Lektion und renderst sie mit `KrgzHayali`. Stelle sicher, dass du zuerst die
[Einrichtung](/hayali/setup) abgeschlossen hast: Header, Styles, Übersetzungen und einen bereitgestellten WebContainer.

::hint
Sofern nicht anders angegeben, stammen alle Importe aus `@karagoz/hayali`.
::

## Eine minimale Lektion

Eine Lektion ist ein einfaches Objekt. Sie hat einen Basis-Dateibaum (`files`) und eine Liste von Kapiteln, die aus
Schritten bestehen. Hier ist eine Lektion mit einem Kapitel und zwei Schritten. Der zweite Schritt ändert `index.html`
und sagt dem Editor, worauf er achten soll.

```typescript
import type { Lesson } from '@karagoz/hayali'

const file = (contents: string) => ({ file: { contents } })

export const lesson: Lesson = {
  // Mounted at boot. `package.json` and `server.js` are never reset because they are listed as immutable.
  files: {
    'package.json': file(JSON.stringify({ scripts: { start: 'node server.js' } })),
    'server.js': file(`
      const http = require('http')
      const fs = require('fs')
      http.createServer((req, res) => {
        fs.readFile('index.html', (error, html) => res.end(error ? 'Not found' : html))
      }).listen(3000)
    `),
    'index.html': file('<h1>Hello</h1>'),
  },
  immutable: ['package.json', 'server.js'],
  chapters: [
    {
      id: 'intro',
      title: 'Introduction',
      steps: [
        {
          id: 'hello',
          title: 'Say hello',
          body: 'This is the page. Open **index.html** and change the heading.',
          editor: { open: ['index.html'] },
        },
        {
          id: 'shout',
          title: 'Make it loud',
          body: 'The heading is now louder.',
          adjustments: { 'index.html': file('<h1>HELLO!</h1>') },
          editor: {
            open: ['index.html'],
            highlight: [{ path: 'index.html', lines: 1 }],
          },
        },
      ],
    },
  ],
}
```

Die IDs wählst du selbst, und sie müssen eindeutig sein (Schritt-IDs innerhalb ihres Kapitels, Kapitel-IDs innerhalb der
Lektion). Sie werden nie aus Titeln abgeleitet, sodass du einen Titel umbenennen kannst, ohne Links oder gespeicherte
Positionen zu brechen.

## Prüfen

`validateLesson()` ist eine reine Funktion, du kannst sie also in einem Unit-Test oder Build-Skript ohne Browser
ausführen. Sie meldet Direktiven, die auf fehlende Dateien zeigen, ungültige Zeilennummern, ungültige Pfade und mehr:

```typescript
import { validateLesson } from '@karagoz/hayali'

const issues = validateLesson(lesson)
if (issues.length) console.error(issues)
```

## Rendern

Stelle den WebContainer bereit, halte die Position in einem Ref und übergib beides an `KrgzHayali`. Gib der Komponente
eine Höhe: Sie füllt ihr Elternelement aus.

```vue
<script setup lang="ts">
import { KrgzHayali } from '@karagoz/hayali'
import { provideWebContainer, useSandboxBoot } from '@karagoz/sandbox'
import { ref } from 'vue'

import { lesson } from './lesson'

provideWebContainer(useSandboxBoot().boot)
const position = ref({ chapterId: 'intro', stepId: 'hello' })
</script>

<template>
  <div style="height: 640px">
    <KrgzHayali :lesson="lesson" v-model:position="position" />
  </div>
</template>
```
