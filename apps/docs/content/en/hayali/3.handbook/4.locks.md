# Locks

A **lock** makes a file read-only for the duration of one step. It is a UI restriction only: the learner can still
open and read a locked file, they just cannot edit it.

```typescript
{
  id: 'style',
  title: 'Style',
  body: '…',
  adjustments: styled,
  locks: ['index.html'],   // read-only in this step
}
```

`locks` takes path patterns (for example `src/**` or `public/*.css`). When a step has locks, a short notice above the
step body lists the locked files.

## Locks versus immutability

|  | Lock | Immutable |
| --- | --- | --- |
| Scope | One step | The whole lesson |
| Effect | Read-only in the explorer and editor | Never tracked or reset |
| Set with | `Step.locks` | `Lesson.immutable` |

They are orthogonal. A locked file that is not immutable still resets when the learner moves on. A locked file can
still be opened, closed and highlighted by [editor directives](/hayali/handbook/editor-directives).
