# Layout

`KrgzHayali` has two layouts: **side by side** (lesson on the left, sandbox on the right, with a resize handle) and a
**single panel** with a Lesson/Sandbox toggle. Which one you get depends on the width of the **component**, not of the
viewport, so a lesson in a narrow column behaves like a lesson on a phone.

## fullLayoutFrom

The `fullLayoutFrom` prop sets the minimum width for the side-by-side layout. It takes the container sizes
`xs`, `sm`, `md`, `lg`, `xl`, `2xl`, `3xl` (the default), `4xl`, `5xl`, `6xl` or `7xl` (as in Tailwind's container
queries: `3xl` is 48rem), or `none` to always use the single panel.

```vue
<KrgzHayali :lesson="lesson" v-model:position="position" full-layout-from="4xl" />
```

The choice is made by CSS alone, so the right layout is there on the very first paint, including in server-rendered
HTML, without waiting for JavaScript. JavaScript only keeps track of which panel the toggle shows and handles the resize
handle.

## multiPanelFrom

`multiPanelFrom` is forwarded to the sandbox, which switches between showing the editor, explorer and preview side by
side and one at a time. See the [Sandbox handbook](/sandbox/handbook/working-with-panels).

## Sizing

The component fills its parent (`height: 100%`), so give the parent a height, for example `height: 640px` or a flex
child that grows.

## Replacing the sandbox

The sandbox pane renders `KrgzSandbox` by default. To use your own arrangement, fill the `sandbox` slot. It receives
`ready` (whether the files are mounted) and `multiPanelFrom`:

```vue
<KrgzHayali :lesson="lesson" v-model:position="position">
  <template #sandbox="{ ready, multiPanelFrom }">
    <MyCustomSandbox :booting="!ready" :multi-panel-from="multiPanelFrom" />
  </template>
</KrgzHayali>
```

## Right to left

The layout follows the document direction. The toolbar's Prev and Next icons are mirrored in right-to-left languages.
