# Callouts

Step bodies are markdown. On top of regular markdown they support **callouts**: highlighted boxes for a tip, a warning
or a note. A callout is a fenced container with a kind and an optional title:

```markdown
:::tip A short title
Some helpful advice. It can contain *regular* markdown.
:::

:::warning
No title is fine, too.
:::
```

Three kinds ship by default:

| Kind | Use it for |
| ---- | ---------- |
| `tip` | Advice that helps but is not required. |
| `warning` | Something that can go wrong or lose work. |
| `note` | Neutral extra information. |

An unknown kind is not rendered as a callout; it stays plain text.

## Rendering your own markdown

`KrgzHayali` renders the bodies of its steps with the default kinds. The pieces behind it are exported, so you can use
the same syntax in your own markdown-it based rendering, or add your own kinds:

* [`createCalloutRegistry()`](/hayali/api-reference/functions/createCalloutRegistry) creates a registry of
  [`CalloutDefinition`](/hayali/api-reference/interfaces/CalloutDefinition)s; call `register(kind, { variant })` to add
  or replace one.
* [`calloutPlugin(registry)`](/hayali/api-reference/functions/calloutPlugin) is the markdown-it plugin that turns the
  containers into styled alerts.
* `StepBody` renders one markdown string with the default registry.

```typescript
import MarkdownIt from 'markdown-it'
import { calloutPlugin, createCalloutRegistry } from '@karagoz/hayali'

const registry = createCalloutRegistry()
registry.register('danger', { variant: 'destructive' })

const html = new MarkdownIt().use(calloutPlugin(registry)).render(':::danger Careful\nSharp edges.\n:::')
```
