# Karagöz Hayali

::hint{variant='warning'}
Karagöz Hayali is free to use, and you are welcome to try it. It is provided "as is", with no guarantee of any kind, and we take no responsibility for any damage resulting from its use.

Feedback and improvement ideas are welcome by opening issues and discussions in the
:external-link{href='https://github.com/frontendat/karagoz' content='GitHub repo'}.
::

*Hayalî* is the shadow-play master who tells the story behind the screen. Karagöz Hayali does the same for code: it
turns a **lesson** into a guided walkthrough, with the explanation on one side and a live
[Karagöz Sandbox](/sandbox) on the other.

An author writes a lesson as plain data: **chapters** made of **steps**. Each step carries a markdown body and
describes the state of the sandbox it is about:

* the files it **adds or changes** (adjustments) and the ones it **removes**,
* which files are **locked** against editing,
* which files to **open**, which lines to **highlight** and where to place the cursor (editor directives),
* which page the **preview** should show.

The learner moves through the steps with the toolbar or the step list. Every step starts from a known state: edits are
reset when moving on (after a confirmation), so nobody gets lost in a half-broken project.

## Why use it

* **Server-renderable.** The lesson text is in the server HTML, so it is readable without JavaScript and by search
  engines. The layout is pure CSS and adapts to the width of the component, not the viewport.
* **Built on the Sandbox.** Everything the learner types runs in a real WebContainer.

## See it in action

::hint
Due to limitations set in the design of the WebContainer API, **only one** WebContainer instance can be running at a 
time. 
Because of that, starting one of the demos on one of the documentation pages will terminate any previously running demos.
::

::hint
Depending on your use case, you might need a commercial license to use the WebContainer API.
Please refer to :external-link{href='https://webcontainers.io/enterprise' content='this page'} for more information.
::
