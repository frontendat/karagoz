# Getting Started

This guide builds a small lesson and renders it with `KrgzHayali`. Make sure you completed the [Setup](/hayali/setup)
first: headers, styles, translations and a provided WebContainer.

::hint
Unless otherwise mentioned, all imports come from `@karagoz/hayali`.
::

## A minimal lesson

A lesson is a plain object. It has a base file tree (`files`) and a list of chapters made of steps. Here is a lesson
with one chapter and two steps. The second step changes `index.html` and tells the editor what to look at.

```typescript
import type { Lesson } from '@karagoz/hayali'

const file = (contents: string) => ({ file: { contents } })

export const lesson: Lesson = {
  // Mounted at boot. `package.json` and `server.js` are never reset because they are listed as immutable.
  files: {
    'package.json': file(JSON.stringify({ scripts: { start: 'node server.js' } })),
    'server.js': file(`
      const http = require('http')
      const fs = require('fs')
      http.createServer((req, res) => {
        fs.readFile('index.html', (error, html) => res.end(error ? 'Not found' : html))
      }).listen(3000)
    `),
    'index.html': file('<h1>Hello</h1>'),
  },
  immutable: ['package.json', 'server.js'],
  chapters: [
    {
      id: 'intro',
      title: 'Introduction',
      steps: [
        {
          id: 'hello',
          title: 'Say hello',
          body: 'This is the page. Open **index.html** and change the heading.',
          editor: { open: ['index.html'] },
        },
        {
          id: 'shout',
          title: 'Make it loud',
          body: 'The heading is now louder.',
          adjustments: { 'index.html': file('<h1>HELLO!</h1>') },
          editor: {
            open: ['index.html'],
            highlight: [{ path: 'index.html', lines: 1 }],
          },
        },
      ],
    },
  ],
}
```

IDs are chosen by you and must be unique (step IDs within their chapter, chapter IDs within the lesson). They are never
derived from titles, so you can rename a title without breaking links or saved positions.

## Check it

`validateLesson()` is a pure function, so you can run it in a unit test or a build script without a browser. It reports
directives that point at missing files, bad line numbers, invalid paths and more:

```typescript
import { validateLesson } from '@karagoz/hayali'

const issues = validateLesson(lesson)
if (issues.length) console.error(issues)
```

## Render it

Provide the WebContainer, keep the position in a ref and pass both to `KrgzHayali`. Give the component a height: it
fills its parent.

```vue
<script setup lang="ts">
import { KrgzHayali } from '@karagoz/hayali'
import { provideWebContainer, useSandboxBoot } from '@karagoz/sandbox'
import { onBeforeUnmount, ref } from 'vue'

import { lesson } from './lesson'

const { boot } = useSandboxBoot()
provideWebContainer(boot)
onBeforeUnmount(() => void boot.then((container) => container.teardown()))

const position = ref({ chapterId: 'intro', stepId: 'hello' })
</script>

<template>
  <div style="height: 640px">
    <KrgzHayali :lesson="lesson" v-model:position="position" />
  </div>
</template>
```
