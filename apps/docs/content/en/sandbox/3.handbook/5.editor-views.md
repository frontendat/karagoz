# Editor Views

The `editorViews` property of the sandbox instance lets you interact with the contents of open editors: highlight
lines, and go to (scroll to, focus, and place the cursor on) a specific line.

## Highlighting Lines

```ts
// highlight a single line in the currently focused tab
sandbox.editorViews.highlightLines(6)

// highlight an inclusive range of lines
sandbox.editorViews.highlightLines([11, 13])
```

If you pass a file path, that file is opened (and focused, if not already) before the lines are highlighted.

```ts
sandbox.editorViews.highlightLines([5, 7], './public/style.css')
```

## Highlighting Multiple Ranges

`highlightLines()` is additive: calling it again adds another highlighted range rather than replacing the previous
one, so multiple disjoint ranges can be highlighted in the same editor at once.

```ts
sandbox.editorViews.highlightLines(1)
sandbox.editorViews.highlightLines([11, 13])
// both line 1 and lines 11-13 are now highlighted
```

Highlighted lines are retained even after their editor tab is closed, and are automatically restored if the same
file is opened again.

## Clearing Highlights

```ts
// clear highlights in the currently focused tab
sandbox.editorViews.clearHighlightedLines()

// clear highlights in a specific file
sandbox.editorViews.clearHighlightedLines('./public/style.css')

// clear highlights across every open editor
sandbox.editorViews.clearAllHighlightedLines()
```

Both methods also forget any retained highlights for the affected path(s), so they won't be restored the next time
the file is opened. `clearHighlightedLines()` is a no-op if the target file isn't currently open.

## Going To A Line

```ts
// scroll the currently focused tab so line 11 is centered in view, place the cursor there and
// focus the editor
sandbox.editorViews.goToLine(11)

// open (if needed), focus and go to a line in a specific file
sandbox.editorViews.goToLine(11, './server.js')
```

Highlighting and going to a line are independent — call either one without the other. This is also true when opening
a file that isn't loaded yet: `highlightLines()` and `goToLine()` will each open and focus the target file on their
own; you don't need to call `editorTabs.open()` first.
