# التنبيهات

نصوص الخطوات (Step) بصيغة Markdown. وإلى جانب Markdown العادي تدعم **التنبيهات** (Callouts): صناديق بارزة لنصيحة أو تحذير أو ملاحظة.
التنبيه حاوية محاطة بأسوار لها نوع وعنوان اختياري:

```markdown
:::tip A short title
Some helpful advice. It can contain *regular* markdown.
:::

:::warning
No title is fine, too.
:::
```

تأتي ثلاثة أنواع افتراضيًا:

| النوع | يُستخدم من أجل |
| ----- | -------------- |
| `tip` | نصيحة مفيدة وليست ضرورية. |
| `warning` | أمر قد يسوء أو يُضيّع العمل. |
| `note` | معلومة إضافية محايدة. |

النوع غير المعروف لا يُصيَّر تنبيهًا، بل يبقى نصًا عاديًا.

## تصيير Markdown الخاص بك

يصيّر `KrgzHayali` نصوص خطواته بالأنواع الافتراضية. والأجزاء الكامنة وراءه مُصدَّرة، فيمكنك استخدام الصيغة نفسها في تصيير
مبني على markdown-it لديك، أو إضافة أنواع خاصة بك:

* تنشئ [`createCalloutRegistry()`](/hayali/api-reference/functions/createCalloutRegistry) سجلًا من
  [`CalloutDefinition`](/hayali/api-reference/interfaces/CalloutDefinition)؛ استدعِ `register(kind, { variant })` لإضافة نوع أو
  استبداله.
* [`calloutPlugin(registry)`](/hayali/api-reference/functions/calloutPlugin) هي إضافة markdown-it التي تحوّل الحاويات إلى
  تنبيهات منسّقة.
* يصيّر `StepBody` نص Markdown واحدًا بالسجل الافتراضي.

```typescript
import MarkdownIt from 'markdown-it'
import { calloutPlugin, createCalloutRegistry } from '@karagoz/hayali'

const registry = createCalloutRegistry()
registry.register('danger', { variant: 'destructive' })

const html = new MarkdownIt().use(calloutPlugin(registry)).render(':::danger Careful\nSharp edges.\n:::')
```
