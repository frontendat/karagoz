# الأقفال

**القفل** (Lock) يجعل ملفًا للقراءة فقط طوال مدة خطوة (Step) واحدة. وهو قيد في الواجهة فحسب: يمكن للمتعلّم أن يفتح الملف المقفل
ويقرأه، لكنه لا يستطيع تحريره.

```typescript
{
  id: 'style',
  title: 'Style',
  body: '…',
  adjustments: styled,
  locks: ['index.html'],   // read-only in this step
}
```

تقبل `locks` أنماط مسارات (مثل `src/**` أو `public/*.css`). وعندما يكون للخطوة أقفال، يعرض إشعار قصير فوق نص الخطوة الملفات
المقفلة.

## الأقفال وعدم القابلية للتغيير

|  | القفل | غير قابل للتغيير |
| --- | --- | --- |
| النطاق | خطوة واحدة | الدرس (Lesson) كله |
| الأثر | للقراءة فقط في المستكشف والمحرر | لا يُراقَب ولا يُعاد ضبطه |
| يُحدَّد عبر | `Step.locks` | `Lesson.immutable` |

الاثنان مستقلان. فالملف المقفل غير الثابت يُعاد ضبطه عند المتابعة رغم ذلك. ويمكن لـ
[توجيهات المحرر](/hayali/handbook/editor-directives) أن تفتح الملف المقفل وتغلقه وتسلّط الضوء عليه.
