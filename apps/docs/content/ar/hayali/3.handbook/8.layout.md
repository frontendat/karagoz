# التخطيط

لـ `KrgzHayali` تخطيطان: **جنبًا إلى جنب** (الدرس (Lesson) في جانب وSandbox في الجانب الآخر، مع مقبض لتغيير الحجم)، و**لوحة واحدة**
مع مفتاح الدرس/Sandbox. ويعتمد التخطيط الذي تحصل عليه على عرض **المكوّن**، لا نافذة العرض، فيتصرف الدرس في عمود ضيق مثل
الدرس على الهاتف.

## fullLayoutFrom

تحدد الخاصية `fullLayoutFrom` الحد الأدنى للعرض لتخطيط جنبًا إلى جنب. وتقبل أحجام الحاويات
`xs` و`sm` و`md` و`lg` و`xl` و`2xl` و`3xl` (الافتراضي) و`4xl` و`5xl` و`6xl` و`7xl` (كما في استعلامات الحاويات في Tailwind:
`3xl` تساوي 48rem)، أو `none` لاستخدام اللوحة الواحدة دائمًا.

```vue
<KrgzHayali :lesson="lesson" v-model:position="position" full-layout-from="4xl" />
```

يتم الاختيار بواسطة CSS وحده، فيكون التخطيط الصحيح حاضرًا منذ أول عرض، بما في ذلك HTML المصيَّر على الخادم، دون انتظار
JavaScript. ولا تتولى JavaScript سوى تتبّع اللوحة التي يعرضها المفتاح وإدارة مقبض تغيير الحجم.

## multiPanelFrom

تُمرَّر `multiPanelFrom` إلى Sandbox، التي تبدّل بين عرض المحرر والمستكشف والمعاينة جنبًا إلى جنب وعرضها واحدًا تلو الآخر. راجع
[دليل Sandbox](/sandbox/handbook/working-with-panels).

## الحجم

يملأ المكوّن عنصره الأب (`height: 100%`)، فأعطِ العنصر الأب ارتفاعًا، مثل `height: 640px` أو عنصر Flex ينمو.

## استبدال Sandbox

تصيّر لوحة Sandbox المكوّن `KrgzSandbox` افتراضيًا. ولاستخدام ترتيبك الخاص، املأ الفتحة (Slot) المسماة `sandbox`. وهي تستقبل
`ready` (هل حُمّلت الملفات) و`multiPanelFrom`:

```vue
<KrgzHayali :lesson="lesson" v-model:position="position">
  <template #sandbox="{ ready, multiPanelFrom }">
    <MyCustomSandbox :booting="!ready" :multi-panel-from="multiPanelFrom" />
  </template>
</KrgzHayali>
```

## من اليمين إلى اليسار

يتبع التخطيط اتجاه المستند. وتُعكس أيقونتا السابق والتالي في شريط الأدوات في اللغات التي تُكتب من اليمين إلى اليسار.
