# التنقّل وإعادة الضبط

يتنقّل المتعلّم بين الخطوات (Step) عبر زرَّي السابق/التالي، أو قائمة جدول المحتويات المنسدلة في شريط الأدوات، أو بالنقر على خطوة في
قائمة الخطوات. تعرض قائمة الخطوات خطوات الفصل (Chapter) الحالي؛ أما الفصول فيُوصَل إليها عبر جدول المحتويات.

## الموضع

الخطوة الحالية هي النموذج `position`، أي [`Position`](/hayali/api-reference/interfaces/Position) من `{ chapterId, stepId }`.
اربطه عبر `v-model:position` لقراءته، أو لاستعادة موضع محفوظ، أو للربط المباشر بخطوة. وإن لم تمرّره يبدأ الدرس (Lesson) من أول خطوة في
أول فصل. ولا يخزّن Hayali الموضع بنفسه أبدًا.


معرّفات الخطوات فريدة داخل الفصل فقط، لذا يتكوّن الموضع من `chapterId` و`stepId` معًا. ولا يتولّى Hayali التوجيه (Routing):
اربط النموذج بما يوفّره إطار العمل لديك، كمعامل استعلام (Query) أو هاش (Hash) أو جزء من المسار.

وإذا كان الموضع المربوط يشير إلى خطوة غير موجودة، كرابط قديم مثلًا، يعرض Hayali أول خطوة، ويكتب ذلك الموضع في النموذج
ليصحّح الربط نفسه بنفسه، ويطبع تحذيرًا أثناء التطوير.

## الروابط المباشرة

اربط الموضع بالموجِّه (Router) لديك لتصبح الخطوات قابلة للربط. يحتفظ العرض التوضيحي في هذا الموقع بالموضع في معامل استعلام،
`?step=chapterID/stepID`:

```ts
const route = useRoute()
const router = useRouter()

// ابدأ بالخطوة الأولى ليطابق الـ Hydration ما في HTML، ثم طبّق الرابط بعد التركيب.
const position = ref({ chapterId: 'basics', stepId: 'markup' })
onMounted(() => {
  const linked = parseStep(route.query.step)
  if (linked) position.value = linked
})

// اكتب التغييرات إلى الرابط باستخدام `replace`.
watch(position, ({ chapterId, stepId }) => {
  void router.replace({ query: { ...route.query, step: `${chapterId}/${stepId}` } })
})
```

* **الاستعلام بدل الهاش.** معامل الاستعلام جزء من الطلب ويبقى عند تغيّر المسار، أما الهاش فلا يصل إلى الخادم أبدًا.
* **طبّقه بعد التركيب.** تُقدَّم الصفحات المُصيَّرة مسبقًا بلا معامل الاستعلام، لذا يجب أن يكون أول تصيير هو الخطوة الأولى.
  وتعيين الموضع أثناء الإعداد (Setup) لن يطابق ذلك الـ HTML، فتترك الـ Hydration شريط الأدوات والبيئة التجريبية غير متوافقين مع الخطوة.
  يكفي `onMounted`: فالبيئة التجريبية تبدأ بملفات الخطوة المرتبطة.
* **بادئات اللغة لا تؤثر.** معامل الاستعلام مستقل عن المسار، فيعمل بالطريقة نفسها تحت `/de/` و`/ar/`.
* **`replace` بدل `push`.** تعيين النموذج من الخارج يتجاوز مربع التأكيد وإعادة الضبط، فلو غيّر زر الرجوع الموضع لبقيت
  الملفات غير متوافقة مع الخطوة. اقرأ الرابط عند التحميل فقط.
* **الروابط الخاطئة آمنة.** الرابط المؤدي إلى خطوة لم تعد موجودة يعرض الخطوة الأولى ويصحّح النموذج، فيُصلح رابطك نفسه بنفسه.

## إعادة الضبط ومربع التأكيد

تبدأ كل خطوة من حالة معروفة. وعندما ينتقل المتعلّم، تُعاد الملفات القابلة لإعادة الضبط إلى شجرة الخطوة المستهدفة (انظر
[التعديلات والحذف](/hayali/handbook/adjustments-and-removals)). ويُعدّ الملف **معدَّلًا** (Dirty) بمجرد أن يحرّره المتعلّم. وما دامت
هناك ملفات معدَّلة، يطلب Hayali التأكيد قبل الانتقال إلى خطوة أخرى، لأن التعديلات ستضيع.

* **متابعة** تعيد الملفات إلى أصلها وتنتقل.
* **إلغاء** لا يغيّر شيئًا: لا الموضع ولا الملفات ولا التبويبات المفتوحة ولا المعاينة.

::hint
لا تُراقَب إلا الملفات القابلة لإعادة الضبط. وتعديلات [الملفات غير القابلة للتغيير](/hayali/handbook/adjustments-and-removals)
لا تجعل الدرس «معدَّلًا» أبدًا ولا تُعاد إلى أصلها.
::

## انتقال واحد في كل مرة

التنقّل أحادي المسار (Single-Flight). فمن مربع التأكيد حتى استقرار الخطوة الجديدة، يكون شريط الأدوات وقائمة الخطوات معطّلين،
وتُتجاهل طلبات التنقّل الإضافية؛ ولا تُوضَع في طابور. وتُطبَّق توجيهات المحرر والمعاينة بعد ذلك في الخلفية، وتُلغي الخطوة
الأحدث دائمًا التوجيهات غير المكتملة للخطوة الأقدم.

## عند دخول خطوة

بعد إعادة الضبط، يطبّق Hayali [توجيهات المحرر](/hayali/handbook/editor-directives) للخطوة بترتيب ثابت: مسح التظليلات القديمة،
وإغلاق التبويبات وفتحها، وتسليط الضوء، والانتقال إلى سطر، ثم المعاينة.
