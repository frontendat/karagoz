# SSR وأطر العمل

يصيّر Karagöz Hayali على الخادم. والمقصود أن يكون الدرس (Lesson) مقروءًا دون JavaScript ولمحركات البحث.

## ما يصيّره الخادم

* نص كل خطوة (Step) في الفصل (Chapter) الحالي ضمن HTML. والخطوات غير الحالية مطويّة في الواجهة لكنها موجودة.
* التخطيط، المختار بواسطة CSS (انظر [التخطيط](/hayali/handbook/layout)).
* عنصرًا نائبًا بدلًا من Sandbox. فالـ WebContainer لا يوجد إلا في المتصفح ويُقلع عند التركيب (Mount).
* الخطوة المحددة في `position`، أو أول خطوة في أول فصل إن لم تمرّر موضعًا. ولا يستعيد Hayali موضعًا من `localStorage` أبدًا.

## ما عليك توفيره

* **ترويسات COOP/COEP** للصفحة، ليتمكن المتصفح من تشغيل WebContainers. وفي أثناء التطوير يسجّل Hayali تحذيرًا واحدًا إذا لم تكن
  الصفحة معزولة عبر المصادر.
* **ملفات الأنماط** الخاصة بـ `@karagoz/shared` و`@karagoz/sandbox` و`@karagoz/hayali` ضمن المخرجات المصيَّرة على الخادم.
* **نسخة جديدة من `vue-i18n` لكل تطبيق (ولكل طلب على الخادم)** مع دمج `i18nMessages`، وأخذ اللغة من خاصية (Prop) أو من إطار
  العمل.
* **`provideWebContainer(useSandboxBoot().boot)`** في مكوّن أعلى من `KrgzHayali`. فالإقلاع يحدث عند التركيب فقط، ما يجعل
  الاستدعاء آمنًا أثناء التصيير على الخادم.

## Nuxt

هذا هو الإعداد المستخدم في هذا الموقع نفسه، والمتحقَّق منه عبر العرض التوضيحي في صفحة [البدء](/hayali/getting-started).

```typescript
/* nuxt.config.ts */
export default defineNuxtConfig({
  css: ['~/assets/css/karagoz.css'],            // imports the three @karagoz/* stylesheets
  routeRules: {
    '/*': {
      headers: {
        'Cross-Origin-Embedder-Policy': 'require-corp',
        'Cross-Origin-Opener-Policy': 'same-origin',
      },
    },
  },
  modules: ['@nuxtjs/i18n'],
})
```

```typescript
/* i18n/locales/en.ts: merge the single pack */
export default defineI18nLocale(async () => ({
  ...(await import('@karagoz/hayali')).i18nMessages.en,
  /* your own messages */
}))
```

غلّف الدرس في مكوّن يوفّر WebContainer، وخذ اللغة من `useI18n()`، وصيّره مكوّنًا كسولًا (Lazy) مع `hydrate-on-visible`. يبقى
نص الدرس في HTML الصادر عن الخادم، ولا يُقلع WebContainer إلا عندما يظهر الدرس في نطاق الرؤية:

```vue
<template>
  <LazyMyLessonRunner hydrate-on-visible :locale="locale" />
</template>
```

لا حاجة إلى `<ClientOnly>`.

## Astro

::hint{variant='destructive'}
لم يُتحقَّق من هذه الوصفة بعد. إنها المسار المدعوم استنادًا إلى طريقة عمل Hayali، لكنها غير مجرَّبة.
::

* صيّر الدرس من **جزيرة (Island) Vue واحدة** تحتوي `KrgzHayali` وتوفّر WebContainer.
* أنشئ **نسخة جديدة من `vue-i18n` لكل جزيرة** عبر `appEntrypoint` في تكامل Vue، وادمج `i18nMessages` فيها.
* رطّب (Hydrate) باستخدام `client:visible`، فيُقلع WebContainer عندما تظهر الجزيرة في نطاق الرؤية.
* قدّم ترويسات COOP/COEP من المستضيف أو المحوّل (Adapter)، وضمّن ملفات الأنماط الثلاثة في الصفحة.

```typescript
/* src/pages/_app.ts, registered with vue({ appEntrypoint: '/src/pages/_app' }) */
import type { App } from 'vue'
import { createI18n } from 'vue-i18n'
import { i18nMessages } from '@karagoz/hayali'

export default (app: App) => {
  app.use(createI18n({ legacy: false, locale: 'en', fallbackLocale: 'en', messages: i18nMessages }))
}
```
