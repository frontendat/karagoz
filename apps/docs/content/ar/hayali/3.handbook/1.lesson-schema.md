# مخطط الدرس

الدرس (Lesson) بيانات بسيطة. وهذا مقصود: يمكنك حفظه في ملف، وتوليده، وترجمته، والتحقق منه دون متصفح.

| المفهوم | النوع | ما هو |
| ------- | ----- | ----- |
| الدرس (Lesson) | [`Lesson`](/hayali/api-reference/interfaces/Lesson) | الكل: الملفات الأساسية مع الفصول. |
| الفصل (Chapter) | [`Chapter`](/hayali/api-reference/interfaces/Chapter) | مجموعة خطوات لها عنوان. |
| الخطوة (Step) | [`Step`](/hayali/api-reference/interfaces/Step) | شاشة شرح واحدة وحالة Sandbox التي تتناولها. |
| الموضع (Position) | [`Position`](/hayali/api-reference/interfaces/Position) | `{ chapterId, stepId }`: أين يقف المتعلّم. |

## المعرّفات

للفصول والخطوات معرّف `id` **تختاره أنت**. معرّفات الخطوات فريدة داخل فصلها، ومعرّفات الفصول فريدة داخل الدرس. ولا تُشتق
المعرّفات من العناوين أبدًا. استخدمها لحفظ الموضع واستعادته، أو لربط الترجمات.

## ما يمكن أن تحمله الخطوة

* `title` و`body` (بصيغة Markdown، مع [التنبيهات](/hayali/handbook/callouts)).
* `adjustments` و`removals`: [الملفات التي تغيّرها الخطوة](/hayali/handbook/adjustments-and-removals).
* `locks`: [الملفات المقروءة فقط في الخطوة](/hayali/handbook/locks).
* `editor` و`preview`: [أين يُوجَّه انتباه المتعلّم](/hayali/handbook/editor-directives).

كل شيء عدا `id` و`title` و`body` اختياري. وأي درس كُتب لإصدار سابق، دون `editor` أو `preview`، يواصل العمل دون تغيير.

## التحقق

تفحص [`validateLesson()`](/hayali/api-reference/functions/validateLesson) الدرس مقابل شجرة الملفات المحلولة لكل خطوة، وتعيد
قائمة من [`LessonIssue`](/hayali/api-reference/interfaces/LessonIssue). القائمة الفارغة تعني أن الدرس صالح. ولا ترمي الدالة
استثناءً أبدًا، حتى مع المدخلات المشوّهة، فيمكن تشغيلها على دروس محمّلة من JSON.

```typescript
const issues = validateLesson(lesson)
// e.g. { rule: 'missing-file', chapterId: 'intro', stepId: 'shout', path: 'app.js', message: '…' }
```
