# البدء

في هذا الدليل ستبني درسًا (Lesson) صغيرًا وتصيّره باستخدام `KrgzHayali`. تأكد من إتمام [الإعداد](/hayali/setup) أولًا: الترويسات
والأنماط والترجمات وتوفير WebContainer.

::hint
ما لم يُذكر خلاف ذلك، فإن جميع عمليات الاستيراد تأتي من `@karagoz/hayali`.
::

## درس بسيط

الدرس كائن بسيط. له شجرة ملفات أساسية (`files`) وقائمة فصول (Chapters) تتألف من خطوات (Steps). إليك درسًا بفصل واحد وخطوتين.
تعدّل الخطوة الثانية الملف `index.html` وتخبر المحرر بما ينبغي النظر إليه.

```typescript
import type { Lesson } from '@karagoz/hayali'

const file = (contents: string) => ({ file: { contents } })

export const lesson: Lesson = {
  // Mounted at boot. `package.json` and `server.js` are never reset because they are listed as immutable.
  files: {
    'package.json': file(JSON.stringify({ scripts: { start: 'node server.js' } })),
    'server.js': file(`
      const http = require('http')
      const fs = require('fs')
      http.createServer((req, res) => {
        fs.readFile('index.html', (error, html) => res.end(error ? 'Not found' : html))
      }).listen(3000)
    `),
    'index.html': file('<h1>Hello</h1>'),
  },
  immutable: ['package.json', 'server.js'],
  chapters: [
    {
      id: 'intro',
      title: 'Introduction',
      steps: [
        {
          id: 'hello',
          title: 'Say hello',
          body: 'This is the page. Open **index.html** and change the heading.',
          editor: { open: ['index.html'] },
        },
        {
          id: 'shout',
          title: 'Make it loud',
          body: 'The heading is now louder.',
          adjustments: { 'index.html': file('<h1>HELLO!</h1>') },
          editor: {
            open: ['index.html'],
            highlight: [{ path: 'index.html', lines: 1 }],
          },
        },
      ],
    },
  ],
}
```

تختار المعرّفات (IDs) بنفسك ويجب أن تكون فريدة (معرّفات الخطوات داخل فصلها، ومعرّفات الفصول داخل الدرس). ولا تُشتق أبدًا من
العناوين، فيمكن تغيير أي عنوان دون كسر الروابط أو المواضع المحفوظة.

## التحقق

الدالة `validateLesson()` دالة نقية، فيمكن تشغيلها في اختبار وحدة أو سكربت بناء دون متصفح. وهي تبلّغ عن التوجيهات التي تشير إلى
ملفات غير موجودة، وأرقام الأسطر الخاطئة، والمسارات غير الصالحة، وغير ذلك:

```typescript
import { validateLesson } from '@karagoz/hayali'

const issues = validateLesson(lesson)
if (issues.length) console.error(issues)
```

## التصيير

وفّر WebContainer، واحتفظ بالموضع في مرجع (Ref)، ومرّرهما إلى `KrgzHayali`. أعطِ المكوّن ارتفاعًا، فهو يملأ عنصره الأب.

```vue
<script setup lang="ts">
import { KrgzHayali } from '@karagoz/hayali'
import { provideWebContainer, useSandboxBoot } from '@karagoz/sandbox'
import { onBeforeUnmount, ref } from 'vue'

import { lesson } from './lesson'

const { boot } = useSandboxBoot()
provideWebContainer(boot)
onBeforeUnmount(() => void boot.then((container) => container.teardown()))

const position = ref({ chapterId: 'intro', stepId: 'hello' })
</script>

<template>
  <div style="height: 640px">
    <KrgzHayali :lesson="lesson" v-model:position="position" />
  </div>
</template>
```

## التجربة

هذا هو الدرس التوضيحي المستخدم في أنحاء التوثيق، *A tiny counter page*. له فصلان وخمس خطوات، ويستخدم كل الميزات: تنبيهًا
(Callout)، وقفلًا، وتسليط ضوء، وفتح ملف عند سطر معيّن، و`preview.url`، وحذفًا، وشكلَي `close` معًا. تنقّل بين الخطوات وراقب
كيف يتبعك المحرر والمعاينة.
