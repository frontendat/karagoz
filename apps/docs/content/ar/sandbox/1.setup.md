# الإعداد

إعداد Karagöz Sandbox أمر بسيط، ويكفي اتباع الخطوات أدناه.

## التثبيت

ثبّت الحزم التالية باستخدام مدير الحزم المفضّل.

```shell
# NPM
npm install --save @karagoz/sandbox @karagoz/shared

# PNPM
pnpm add @karagoz/sandbox @karagoz/shared

# Yarn
yarn add @karagoz/sandbox @karagoz/shared

# Bun
bun add @karagoz/sandbox @karagoz/shared
```

::hint
**`@karagoz/shared`** مكتبة منفصلة توفّر مجموعة من مكوّنات
:external-link{href='https://www.shadcn-vue.com' content='shadcn-vue'} المشتركة (ومعظمها دون تعديل)، لاستخدامها في
جميع مشاريع Karagöz.
::

## العزل عبر المصادر (Cross-Origin Isolation)

ورد في توثيق WebContainer API ما يلي:

> تتطلب WebContainers وجود SharedArrayBuffer، وهذا بدوره يتطلب أن يكون الموقع الذي تعمل عليه معزولًا عبر المصادر (cross-origin isolated). لذلك يجب ضبط ترويسات COOP/COEP:
> ```kotlin
> Cross-Origin-Embedder-Policy: require-corp
> Cross-Origin-Opener-Policy: same-origin
> ```

لمعرفة المزيد عن هذا الموضوع، يمكن مراجعة :external-link{href='https://webcontainers.io/guides/configuring-headers' content='Configuring Headers'}
في توثيق WebContainer API.

لإعداد خادم التطوير، طبّق التعديلات التالية:

### مشروع Vue.js

أضف ما يلي إلى إعدادات Vite:

```typescript
export default defineConfig({
  server: {
    headers: {
      'Cross-Origin-Embedder-Policy': 'require-corp',
      'Cross-Origin-Opener-Policy': 'same-origin',
    },
  },
})
```

### مشروع Nuxt

أضف ما يلي إلى إعدادات Nuxt:

```typescript
export default defineNuxtConfig({
  routeRules: {
    '/*': {
      headers: {
        'Cross-Origin-Embedder-Policy': 'require-corp',
        'Cross-Origin-Opener-Policy': 'same-origin',
      },
    },
  },
  hooks: {
    // routeRules should be enough to get things running, but without the following Nuxt DevTools won't work.
    'vite:serverCreated': (server) => {
      server.middlewares.use((_req, res, next) => {
        res.setHeader('Cross-Origin-Resource-Policy', 'same-origin')
        res.setHeader('Cross-Origin-Embedder-Policy', 'require-corp')
        res.setHeader('Cross-Origin-Opener-Policy', 'same-origin')
        res.setHeader('Access-Control-Allow-Origin', 'https://localhost:3000')
        next()
      })
    },
  },
})
```

## الأنماط (Styles)

بعد التثبيت، يجب استيراد ملفات الأنماط.

يمكن فعل ذلك مثلًا في ملف نقطة الدخول على النحو التالي:

```typescript
/* main.ts */
import '@karagoz/shared/dist/karagoz-shared.css'
import '@karagoz/sandbox/dist/karagoz-sandbox.css'
```

أو في ملف الأنماط الرئيسي:

```css
/* main.css */
@import "@karagoz/shared/dist/karagoz-shared.css";
@import "@karagoz/sandbox/dist/karagoz-sandbox.css";
```

## الترجمة (I18N)

يستخدم Karagöz Sandbox مكتبة `vue-i18n` لتوفير واجهة مترجمة. ويأتي مزوّدًا بترجمات للعربية والإنجليزية والألمانية،
ولأن عدد النصوص المطلوب ترجمتها قليل، فمن السهل إضافة دعم لأي لغة أخرى.

```typescript
/* main.ts */

import { createApp } from 'vue'
import App from './App.vue'
import { createI18n } from 'vue-i18n'
import { i18nMessages } from '@karagoz/sandbox'

const i18n = createI18n({
  locale: 'en',
  messages: { 
    /* Already supported languages */ 
    ar: { ...i18nMessages.ar },
    de: { ...i18nMessages.de },
    en: { ...i18nMessages.en },
    /* Additional language */
    fr: {
      /* All Karagöz translations are under the krgz key/prefix. */
      krgz: {
        /* ... */
      }
    }
  }
})

createApp(App).use(i18n).mount('#app')
```

للحصول على أمان الأنواع (Type Safety) وتجنّب الترجمات الناقصة، يمكن توسيع `vue-i18n` على النحو التالي:

```typescript
/* vue-i18n.d.ts */

import { i18nMessages } from '@karagoz/sandbox'

type MessageSchema = typeof i18nMessages.en

/**
 * Provide type intellisense for translation keys and date/number formats.
 */
declare module 'vue-i18n' {
  // define the locale messages schema
  export interface DefineLocaleMessage extends MessageSchema {}
}
```
