# الخصائص والأحداث


## الخصائص (Props)

إلى جانب نماذج اللوحات، يقبل `KrgzSandbox` بعض الرايات (Flags) لضبط ظهور بعض الميزات:

### `booting`

عند تمريرها بالقيمة `true`، يظهر مؤشر تحميل. من المهم تمريرها لتجنّب عرض اللوحات قبل أن يصبح WebContainer جاهزًا.

### `hideExplorer`

عند تمريرها بالقيمة `true`، يُخفى مستكشف الملفات (مثلًا لعرض مجموعة محددة فقط من تبويبات المحرر).

### `hideFullScreenToggle`

عند تمريرها بالقيمة `true`، يُخفى مفتاح تبديل الشاشة الكاملة.

### `hideSolveButton`

عند تمريرها بالقيمة `true`، يُخفى زر الحل إن لم تكن هناك حاجة إليه.

### `hideThemeToggle`

عند تمريرها بالقيمة `true`، يُخفى مفتاح التبديل بين السمة الفاتحة والداكنة.

### `multiPanelFrom`

تحدد عرض الحاوية الذي ينتقل عنده `KrgzSandbox` بين تخطيطيه (انظر
[العمل مع اللوحات](/sandbox/handbook/working-with-panels#التخطيط-layout)):
* **تخطيط سطح المكتب:** التخطيط ذو الصفوف الأربعة، مع شريط أدوات ولوحات رئيسية وشريط أدوات ولوحة للدُرج.
* **تخطيط الأجهزة المحمولة:** تخطيط بلوحة واحدة، مع قائمة إضافية في الأعلى وشريط تبويبات في الأسفل للتنقل بين
  اللوحات.

<br>

* **القيم المتاحة:** <br> `none`، `xs`، `sm`، `md`، `lg`، `xl`، `2xl`، `3xl`، `4xl`، `5xl`، `6xl`، `7xl`
* تحدد القيمة الحد الأدنى لعرض الحاوية الذي يُستخدم عنده تخطيط سطح المكتب، ولهذا الغرض تُستخدم
  :external-link{href='https://github.com/tailwindlabs/tailwindcss-container-queries' content='tailwindcss-container-queries'}.
* القيمة الإضافية `none` تفرض تخطيط اللوحة الواحدة للأجهزة المحمولة بغضّ النظر عن عرض الحاوية.
* إذا لم تُمرَّر أي قيمة أو مُرِّرت `undefined`، يُستخدم تخطيط سطح المكتب دائمًا.
* في تخطيط الأجهزة المحمولة تظهر في البداية أول لوحة في `shown-panels`، وبعد ذلك تظهر آخر لوحة جرى التبديل إليها
  (إذ تُنقل اللوحات التي يجري التبديل إليها إلى بداية `shown-panels`).

## الأحداث (Events)

يُطلق `KrgzSandbox` حدثًا واحدًا فقط.

### `solve`

يُطلق عند النقر على زر الحل (إن لم يكن مخفيًا).

لا توجد طريقة محددة للتعامل مع هذا الحدث، لكنه يتضمن عادةً تحميل ملفات جديدة أو إعادة تحميل ملفات موجودة في
WebContainer لعرض النتيجة المطلوبة.

```vue
<script setup lang="ts">
const onSolveClick = async () => {
  sandbox.container.value?.mount({
    public: {
      directory: {
        "about.html": {
          file: {
            contents: "..."
          }
        },
        "index.html": {
          file: {
            contents: "..."
          }
        }
      }
    }
  })
}
</script>

<template>
  <KrgzSandbox
    :booting="isBooting"
    @solve="onSolveClick()"
  ></KrgzSandbox>
</template>
```

في المثال التالي، يؤدي النقر على زر الحل إلى جلب `FileSystemTree` بعيد من نقطة وصول على الخادم وتحميله في
WebContainer، فيُعدَّل `index.html` بإضافة شريط تنقل علوي، وتُنشأ صفحة إضافية هي `about.html`.
