# تبويبات العمليات

الخاصية `processTabs` في الـ Sandbox مسؤولة عن تبويبات العمليات (Process Tabs)، التي تُدار من خلالها العمليات والطرفيات.

## الإقلاع التلقائي (Bootstrapping)

في حالات الاستخدام البسيطة، لن تكون هناك حاجة لإدارة العمليات مباشرة.
إذ يوفّر Karagöz Sandbox الدالة `bootstrap` التي تقوم بما يلي:
1. إنهاء عملية تثبيت الاعتماديات وخادم التطوير إن كان أي منهما قيد التشغيل.
2. **في التشغيل الأول:** الاستماع لأحداث تغيّر العنوان (URL) في إطار المعاينة، لإرسال آخر عنوان إلى النافذة الأم.
   وهذا ضروري لعرض العنوان الحالي في شريط عنوان المعاينة.
3. فتح نافذة طرفية إن كانت خيارات الـ Sandbox تسمح بذلك.
4. تثبيت الاعتماديات (باستخدام مدير الحزم المحدد في الخيارات).
5. تشغيل خادم التطوير (باستخدام مدير الحزم المحدد في الخيارات أيضًا).
6. **في التشغيل الأول:** مراقبة مجلد العمل الحالي لإعادة الإقلاع عند تغيّر ملف يستلزم إعادة التثبيت
   (مثل `package.json`).

## الإدارة اليدوية للعمليات

يمكن الاستغناء عن الإقلاع التلقائي ببساطة بعدم استدعاء `sandbox.bootstrap()`، وعندها يصبح التحكم كاملًا في العمليات
التي تُشغَّل وترتيب تشغيلها.

## تشغيل عملية

سواء استُخدم الإقلاع التلقائي أم لا، يمكن تشغيل العمليات يدويًا عبر استدعاء `processTabs.open()`.

```ts
sandbox.processTabsopen(
  // Unique id. As a convention, you can use the string presentation of the command to run.
  'npm install',
  
  // Optional label to show for the process tab. 
  // If not provided, the process tab ID is shown instead.
  'Install', 
     
  // Optional context.
  {
     // The only mandatory property. The command to spawn the process with.
     command: 'npm',
     // Additional arguemtns.
     arguments: ['install', '--frozen-lockfile'],
     
     // Flags to enable/disable certain UI features (all false by default).
     canRestart: false,
     canStop: false,
     isHidden: false,
     suppressClose: false,
     suppressInput: false,
     
     // When true, the process is treated as a terminal: 
     // some flags are ignored and the tab will be shown in the
     // terminals panel and not in the processes panel.
     isTerminal: false,
  },
)
```

يحتوي كائن السياق على بعض الخصائص الإضافية المستخدمة داخليًا.
لمعرفة المزيد عنه، راجع [مرجع الواجهة البرمجية](/sandbox/api-reference/type-aliases/processtabcontext).

عند تمرير مُعرِّف (ID) موجود مسبقًا، يُركَّز على تبويب العملية المقابل دون تشغيل عملية جديدة.

## إيقاف عملية

يمكن إيقاف عملية بإحدى طريقتين:
* استدعاء `sandbox.processTabs.close(id)` الذي ينهي العملية ويغلق تبويبها،
* أو استدعاء `sandbox.processTabs.kill(id)` الذي ينهي العملية لكنه يُبقي تبويبها ظاهرًا ليظل الوصول إلى مخرجاتها
  ممكنًا.

## إعادة تشغيل عملية

يمكن إعادة تشغيل عملية عبر استدعاء `sandbox.processTabs.restart(id)`.

كما تُظهر العمليات التي يتضمن سياقها `canRestart: true` زر إعادة تشغيل لإعادة تشغيل العملية من خلال الواجهة.

## مثال: الإقلاع اليدوي

لنجمع كل ما سبق ونشغّل العمليات يدويًا.

في العرض التوضيحي أدناه، لا تُشغَّل أي عملية تلقائيًا، بل توجد أزرار من أجل:
* بدء تثبيت الاعتماديات.
* تشغيل خادم التطوير.
* فتح طرفية.
* إغلاق الطرفية إن كانت مفتوحة.

وهذه هي الشيفرة التي تتعامل مع هذه العمليات:

```ts
const installDeps = async () => {
  await sandbox.processTabs.open('npm install', 'Install Dependencies', {
    command: 'npm',
    args: ['install'],
    suppressClose: true,
    suppressInput: true,
  })
  // we await to correctly set installationCompleted flag
  await sandbox.processTabs.findTab('npm install')?.context?.process?.exit
  installationCompleted.value = true
}

const startDevServer = () => {
  sandbox.processTabs.close('npm install')
  // No need to await here because nothing depends on finishing this process
  sandbox.processTabs.open('npm start', 'Dev Server', {
    command: 'npm',
    args: ['start'],
    canRestart: true,
    canStop: true,
    suppressInput: true,
  })
}

const openTerminal = () => {
  sandbox.processTabs.open('terminal', 'Terminal', {
    command: 'jsh',
    isTerminal: true,
  })
}

const closeTerminal = () => {
  sandbox.processTabs.close('terminal')
}
```

## مثال: استخدام المولّدات (Generators)

من حالات الاستخدام الجيدة للإقلاع اليدوي (أو لتشغيل بعض العمليات قبل الإقلاع التلقائي) استخدامُ المولّدات (مثل
`npm create` و`create-react-app` وغيرها).

في المثال أدناه سنولّد تطبيق Vite باستخدام قالب React عبر تشغيل الأمر التالي:
```shell
npm create vite@latest my-react-app -- --template react --no-interactive
```

هناك بعض الأمور التي يجب مراعاتها:
* يتوقع Karagöz Sandbox أن تكون الملفات في مجلد العمل الحالي، بينما تُنشئ المولّدات (عادةً) مجلدًا جديدًا لحفظ
  الملفات المولَّدة. لذلك سيتعيّن نقل جميع الملفات إلى مجلد العمل الحالي بعد التوليد، وحذف المجلد الذي أنشأه المولّد
  بعد أن يصبح فارغًا (اختياريًا).
* ينبغي السعي إلى إلغاء الحاجة لأي إدخال من المستخدم عبر تمرير خيارات الأمر مباشرة. قد لا ينجح ذلك في جميع الحالات،
  لكنه موصى به.
* قد تنفّذ بعض المولّدات خطوات غير مرغوب فيها لا يمكن منعها (مثلًا، يُنشئ مولّد Analog مستودع Git، وهذا لن يعمل
  داخل WebContainer).

وبذلك يكون سير العمل في هذا المثال كما يلي:
1. تشغيل عملية لتنفيذ الأمر `npm create` المذكور أعلاه.
2. نقل جميع الملفات المولَّدة من `./my-react-app` إلى `.`.
3. حذف المجلد `./my-react-app`.
4. تشغيل الإقلاع التلقائي لتثبيت الاعتماديات وتشغيل خادم التطوير.

وبهذا يبدو الخطّاف `onMounted` على النحو التالي تقريبًا:

```ts
onMounted(async () => {
  // Ensure injected promise has been resolved
  const container = await boot
  
  // Mount shell script to perform extra steps before bootstrapping
  await container.mount({
    'prepare.sh': {
      file: {
        contents: [
          'mv ./my-react-app/* ./my-react-app/.* ./',
          'rmdir ./my-react-app',
          'rm prepare.sh',
        ].join('\n'),
      },
    },
  })
  
  // Set start script
  sandbox.setOption('process', (old) => ({
    ...old,
    commands: {
      ...old.commands,
      devServer: 'npm run dev',
    },
  }))
  
  // Generate react app
  await sandbox.processTabs.open('npm create', 'Generating React App', {
    command: 'npm',
    args: 'create vite@latest my-react-app -y -- --template react --no-interactive'.split(' '),
    suppressClose: true,
    suppressInput: true,
  })
  await sandbox.processTabs.findTab('npm create')?.context?.process?.exit
  sandbox.processTabs.close('npm create')
  
  // Perform remaining steps before bootstrapping
  await sandbox.processTabs.open('prepare', 'Prepare', {
    command: 'jsh',
    args: ['prepare.sh'],
    isHidden: true,
  })
  
  // Hand over to bootstrap()
  await sandbox.bootstrap()
  
  sandbox.editorTabs.open('./src/App.jsx')
})
```
