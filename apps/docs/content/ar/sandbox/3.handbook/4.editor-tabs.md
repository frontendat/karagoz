# تبويبات المحرر

يمكن التفاعل مع تبويبات المحرر عبر الخاصية `editorTabs` في نسخة الـ Sandbox، وهي مستخدمة داخليًا أيضًا للتفاعل بين
المستكشف وتبويبات المحرر.

## فتح الملفات

حالة الاستخدام الرئيسية هي فتح الملفات للتحرير بعد التأكد من تحميلها.

```ts
await container.mount(/* FileSystemTree or snapshot */)
await sandbox.bootstrap()

sandbox.editorTabs.open(
  // File path, will be used as a unique ID as well.
  './public/index.html',
  
  // Optional label to by display for the editor tab.
  // If not provided the file name will be extracted 
  // from the path and used as a label.
  'HOME PAGE',
  
  // Optional context. 
  // Currently only supports suppressClose to hide the close button,
  // prventing the user from closing the tab.
  {
    suppressClose: true,
  }
)
```

فتح ملف مفتوح مسبقًا يعيد التركيز ببساطة إلى تبويب المحرر الخاص به.

أما فتح ملف للقراءة فقط (مطابق لـ `sandbox.explorer.readonly`) فيُظهر أيقونة قفل بجانب عنوان التبويب، ويمنع تغيير
محتوى الملف في المحرر.

## إغلاق الملفات

يمكن أيضًا إغلاق تبويبات المحرر برمجيًا عبر تمرير مسار الملف.

```ts
sandbox.editorTabs.close('./public/index.html')
```
