# عروض المحرر

تتيح الخاصية `editorViews` في نسخة الـ Sandbox التفاعل مع محتوى المحررات المفتوحة: تمييز الأسطر، والانتقال إلى سطر
معيّن (التمرير إليه وتركيز المحرر ووضع المؤشر فيه).

## تمييز الأسطر

```ts
// highlight a single line in the currently focused tab
sandbox.editorViews.highlightLines(6)

// highlight an inclusive range of lines
sandbox.editorViews.highlightLines([11, 13])
```

عند تمرير مسار ملف، يُفتح ذلك الملف (ويُركَّز عليه إن لم يكن كذلك) قبل تمييز الأسطر.

```ts
sandbox.editorViews.highlightLines([5, 7], './public/style.css')
```

## تمييز عدة نطاقات

الدالة `highlightLines()` تراكمية: استدعاؤها مرة أخرى يضيف نطاقًا مميزًا جديدًا بدلًا من استبدال النطاق السابق،
وبذلك يمكن تمييز عدة نطاقات منفصلة في المحرر نفسه في آنٍ واحد.

```ts
sandbox.editorViews.highlightLines(1)
sandbox.editorViews.highlightLines([11, 13])
// both line 1 and lines 11-13 are now highlighted
```

تبقى الأسطر المميزة محفوظة حتى بعد إغلاق تبويب المحرر الخاص بها، وتُستعاد تلقائيًا عند فتح الملف نفسه مرة أخرى.

## إزالة التمييز

```ts
// clear highlights in the currently focused tab
sandbox.editorViews.clearHighlightedLines()

// clear highlights in a specific file
sandbox.editorViews.clearHighlightedLines('./public/style.css')

// clear highlights across every open editor
sandbox.editorViews.clearAllHighlightedLines()
```

كما تتجاهل كلتا الدالتين أي تمييز محفوظ للمسارات المعنية، فلا يُستعاد عند فتح الملف في المرة التالية. ولا يكون
لاستدعاء `clearHighlightedLines()` أي أثر إذا لم يكن الملف المستهدف مفتوحًا حاليًا.

## الانتقال إلى سطر

```ts
// scroll the currently focused tab so line 11 is centered in view, place the cursor there and
// focus the editor
sandbox.editorViews.goToLine(11)

// open (if needed), focus and go to a line in a specific file
sandbox.editorViews.goToLine(11, './server.js')
```

التمييز والانتقال إلى سطر مستقلان عن بعضهما — يمكن استدعاء أي منهما دون الآخر. وينطبق ذلك أيضًا عند فتح ملف لم
يُحمَّل بعد: فكل من `highlightLines()` و`goToLine()` يفتح الملف المستهدف ويركّز عليه بنفسه، ولا حاجة لاستدعاء
`editorTabs.open()` أولًا.
