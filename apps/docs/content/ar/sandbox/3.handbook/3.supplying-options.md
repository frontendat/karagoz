# تمرير الخيارات

يوفّر الـ Sandbox الذي تُرجعه `useSandbox` الدالة `setOption`، التي تتيح ضبط خيارات جانب معيّن من الـ Sandbox عبر
تمرير مفتاح وقيمة، أو دالة استدعاء (Callback) تحسب القيمة الجديدة من القيمة القديمة. على سبيل المثال:

```ts
sandbox.setOption('editor', { suppressClose: true })
// or
sandbox.setOption('editor', old => ({ ...old, suppressClose: true }))
```

::hint
سنتعمّق في هذه الصفحة في بعض الخيارات، أما التوثيق الكامل لجميع الخيارات فموجود في توثيق الواجهة البرمجية (انظر
[SandboxOptions](/sandbox/api-reference/type-aliases/sandboxoptions)).
::

يمكن الحصول على نسخة **للقراءة فقط** من الخيارات ببساطة عبر الخاصية `options` في نسخة الـ Sandbox:

```ts
// DO NOT try to set options through assignment here;
// use sandbox.setOption() instead.
sandbox.options.editor
sandbox.options.explorer
sandbox.options.preview
sandbox.options.process
sandbox.options.terminal
```

## خيارات المحرر

**المفتاح: `editor`**

تتضمن خيارات المحرر:
1. `suppressClose`: عند تعيينها إلى `true`، لا تظهر أيقونة "الإغلاق" في تبويبات المحرر. ويمكن تجاوز هذا السلوك
   لكل تبويب على حدة.
2. `theme`: تحدد السمات المستخدمة لتنسيق محررات CodeMirror، وتقبل دالتي استدعاء للسمة الفاتحة والداكنة.

## خيارات المستكشف

**المفتاح: `explorer`**

تتكون خيارات المستكشف من ثلاث مجموعات من مطابِقات المسارات (Path Matchers). وهذه هي مع قيمها الافتراضية:
```ts
sandbox.setOption('explorer', {
  /* determine whether an entity (directory or file) should be hidden in the file explorer. */
  hidden: ['./node_modules/*'],
  /* determine whether an entity should be marked as readonly in the file explorer and editor tabs (lock icon). */
  readonly: [
    '*/node_modules',
    '*/package-lock.json',
    '*/pnpm-lock.yaml',
    '*/yarn.lock',
  ],
  /* determine whether changing an entity should trigger the re-installation of dependencies and re-bootstrapping. */
  reinstall: ['./package.json'],
})
```

## خيارات المعاينة

**المفتاح: `preview`**

تتضمن خيارات المعاينة:
1. `suppressAddressBar`: عند تعيينها إلى `true`، لا يُعرض شريط العنوان فوق إطار المعاينة.
2. `suppressConsole`: عند تعيينها إلى `true`، لا يُعرض زر تبديل وحدة التحكم (Console) بجانب أيقونة إعادة التحميل
   في شريط العنوان. أما لوحة وحدة التحكم، التي تعرض مخرجات `console.log`/`info`/`warn`/`error`/`debug` والأخطاء غير
   المعالَجة من المعاينة، فيظل التحكم بها برمجيًا ممكنًا بغضّ النظر عن هذا الخيار، عبر
   `sandbox.preview.showConsole()` و`sandbox.preview.hideConsole()`. ويمكن قراءة حالتها الحالية من
   `sandbox.preview.consoleShown`.

## خيارات العمليات

**المفتاح: `process`**

تحتوي على ثلاثة خيارات: `packageManager` و`commands` و`starters`.

يحدد `packageManager` مدير الحزم الذي تستخدمه الأوامر، ولا يكون له أثر إلا عندما تستخدم `commands` و`starters`
القيم الافتراضية. وهو أحد `npm` و`pnpm` و`yarn`.

يجب تعيين مدير الحزم قبل استدعاء `sandbox.bootstrap()`.

أما `commands` فهو كائن بثلاثة مفاتيح: `install` و`devServer` و`terminal`، تحتوي على أوامر سطر الأوامر النصية التي
تُنفَّذ للعمليات الافتراضية. ويُعدَّل `install` و`devServer` تلقائيًا عند تغيير الخيار `packageManager`.

وبالمثل، يحتوي `starters` على المفاتيح الثلاثة نفسها: `install` و`devServer` و`terminal`، لكنها هنا دوال استدعاء
لتشغيل العمليات المقابلة. وافتراضيًا تستخدم هذه الدوال نظيراتها في `commands`، وهذا يعني أيضًا أنه عند تعيين أحد
مفاتيح `starters` يُتجاهل نظيره في `commands`.

```ts
sandbox.setOption('process', (old) => ({
  packageManager: 'pnpm', // so commands.install = "pnpm install" and commands.devServer = "pnpm start" 
  commands: {
    ...old.commands,
    devServer: 'pnpm dev', // overriding devServer command default
  },
  starters: {
    ...old.starters,
    terminal: () => { /* new terminal process logic */ }
  },
}))
```

## خيارات الطرفية

**المفتاح: `terminal`**

تتضمن خيارات الطرفية:
1. `maxCount`: الحد الأقصى لعدد تبويبات الطرفية المفتوحة في الوقت نفسه. القيمة الافتراضية: 3.
2. `theme`: تحدد السمات المستخدمة لتنسيق XTerm، وتقبل دالتي استدعاء للسمة الفاتحة والداكنة.
